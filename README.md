# Air-bnb-Dashboard
Built a Global Airbnb Performance Dashboard using Power BI to analyze listings, customer ratings, pricing trends, and market share across major cities.

Key Insights:
✔ Paris, NYC & Sydney dominate Airbnb market share
✔ Airbnb experienced rapid growth between 2011–2015
✔ Mexico City & Rio achieved the highest customer ratings
✔ Entire-place Airbnb stays offer better value than hotels
✔ COVID-19 significantly impacted listing growth in 2020

Tools Used:
🔹 Power BI
🔹 Power Query
🔹 DAX
🔹 Data Cleaning & Visualization
